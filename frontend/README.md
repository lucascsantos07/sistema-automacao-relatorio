# Frontend - Sistema de Automação de Relatórios

Interface web moderna desenvolvida com **Next.js 15**, **React 19** e **CSS Tradicional** em JavaScript puro.

---

## 🚀 Como Executar

1. Entre na pasta `frontend`:
   ```bash
   cd frontend
   ```

2. Instale as dependências:
   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```

4. Abra no navegador: [http://localhost:3000](http://localhost:3000)
